# patelkshitij.com

The source of Kshitij Patel's personal portfolio, live at [www.patelkshitij.com](https://www.patelkshitij.com).

It is a Next.js site that behaves like a single page: a night sky and a purple card stay on screen, and only the content inside the card changes as you move between Home, About, Projects and Contact.

- To run it on your computer, follow [docs/guides/development.md](docs/guides/development.md).
- Before changing anything, read [AGENTS.md](AGENTS.md).
- Every other document is listed in [docs/INDEX.md](docs/INDEX.md).
